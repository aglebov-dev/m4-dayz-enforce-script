# Ссылки и поиск

[← К оглавлению](../../README.ru.md) · [English version](../en/02-references.md)

## Панель ссылок

`Shift+F12` (или **Enforce: Find All References (Panel)**, или контекстное меню редактора)
открывает нижнюю панель **Enforce References**. Сверху — декларации и слои `modded`, ниже —
использования, разложенные на вызовы, чтения, записи, конструкторы и колбэки.

Колонки: `Code`, `Kind`, `File`, `Line`, `Mod`, `Module`, `Containing member`,
`Containing type`. Ширина меняется, есть сортировка и подстрочный фильтр у каждой колонки.

| Кнопка | Что делает |
| --- | --- |
| ⊟ collapse all / ⊞ expand all | Свернуть или развернуть группы |
| ⟲ reset filters | Сбросить все фильтры колонок |
| ⊕ include text matches | Показать текстовые совпадения (строковые литералы, ключи конфигов) |
| ↻ refresh | Перезапросить по текущему индексу |
| 📌 pin | Закрепить результат во вкладке редактора |
| highlight results | Подсветить все попадания в открытых редакторах |

Текстовые совпадения скрыты по умолчанию: за ними нет семантики, а на популярном имени они
топят список. Умолчание — `enforce.references.includeTextMatches` (или
`references.includeTextMatches` в манифесте), кнопка в панели работает в любом случае.

Десять тысяч строк не тормозят.

## Где ищем

По умолчанию — только исходники проекта. Движок и зависимости включаются в манифесте:

```jsonc
"externalReferences": true
```

Выключено по умолчанию: у популярных типов движка тысячи использований.

Резолв идёт по типу: имя сопоставляется тому символу, на который оно реально ссылается, а не
всем однофамильцам корпуса. Перегрузки сужаются по количеству и типам аргументов.

## CodeLens

`N references` / `N layers` над декларациями в файлах проекта, как в Visual Studio. Клик
открывает панель. Выключается настройкой `enforce.codeLensReferences`.

## Дефайны

`Shift+F12` по дефайну перечисляет все `#ifdef` / `#ifndef`, которые его проверяют, `F12` ведёт
к объявлению. См. [Код и редактор](01-editor.md#дефайны-препроцессора).

## Слои modded

**Enforce: Show All Modifications (discovery)** перечисляет все слои `modded` класса по проекту,
зависимостям и движку в порядке загрузки — те же данные, что в попапе hover, но списком.

## Поиск типов

Поиск типов живёт в дереве: кнопка **Search Types** фильтрует дерево по имени, **Filter Symbol
Kinds** оставляет только классы, методы, поля и т. д. См.
[Дерево типов](03-type-explorer.md#тулбар).

## Команды

| Команда | Описание |
| --- | --- |
| `Enforce: Find All References (Panel)` | Панель ссылок для символа под курсором (`Shift+F12`) |
| `Enforce: Show All Modifications (discovery)` | Все слои `modded` класса |
